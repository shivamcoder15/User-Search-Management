# 🔎 User Search Management

A modern and responsive **User Search Management** web application built with **HTML, CSS, JavaScript, and Tailwind CSS**.

The application displays user profile cards with profile images, names, and bios. Users can quickly search for profiles by entering a name in the search field.

## ⚙️ How It Works

The application stores user information in a JavaScript array and dynamically generates user cards.

When a user enters a name in the search box, JavaScript filters the user list and displays only the matching profiles.

A **300ms debounce** is used on the search input to improve the search experience and avoid unnecessary filtering on every keystroke.
